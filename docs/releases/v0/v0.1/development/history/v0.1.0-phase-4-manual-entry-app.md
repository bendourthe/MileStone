## Outcome

A user can add any of the 14 programs, enter balances by hand, sort the dashboard alphabetically or in a custom drag order, and remove programs. Tasks T016 to T019 are complete; T020 is complete except the dashboard screenshot with tiles, which waits on the phone. The phase commit follows the Phase 3 commit.

## Work Done

- `ui/dashboard/DashboardViewModel.kt` and `ui/catalog/CatalogViewModel.kt`: sorting, reorder on drag end, manual entry through `SetManualBalance`, and catalog search with a short debounce (an empty query shows the full list at once).
- `ui/MileStoneApp.kt`: navigation host with typed routes, a bottom bar with Dashboard and Settings tabs, and the sign-in sheet state.
- `ui/dashboard/DashboardScreen.kt` and `ProgramTile.kt`: "MileStone" top bar with the sort menu, Add program button, reorderable tiles in Custom mode with a drag handle and haptic feedback, the logo badge, "Last updated", the formatted balance, the "Manual" label, and a tile menu with Enter balance and Remove (confirmed).
- `ui/catalog/ProgramCatalogScreen.kt`: "Add a program" with a Popular grid (Amex, Chase, Capital One, Delta, United, Marriott), then "Add more" with search and sticky Credit cards, Airlines, and Hotels headers. `ui/dashboard/ManualBalanceDialog.kt` validates input with `ParseBalanceInput`.
- `ui/settings/`: Settings tab with the app version.
- `ui/components/ProgramBadge.kt`: a bundled logo on a white circle, or the monogram in the brand color.
