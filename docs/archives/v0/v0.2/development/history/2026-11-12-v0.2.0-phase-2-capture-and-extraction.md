## Deviations

- The capture build was not changed in `app/src/capture/` to strip identifiers, because the code that saves a capture is in main source outside this plan's write paths. Instead the copy step streams each capture through `app/src/capture/sanitize_capture.py`, so the raw page never reaches the PC; `inspect_capture.py` reports structure with text masked.
- A temporary, uncommitted capture build kept the sign-in window open after a read and stamped the page address; `AuthWebViewModal.kt` was restored after each build.
- Incident: the first sanitizer let 15-character account keys with only 3 digits through. Masked forms (digits replaced) of two keys were printed into the session before the rule was strengthened (runs of 10+ uppercase letters and digits with a digit); all captures were re-sanitized from the phone and verified to hold no such token. `extract.js` uses the stronger rule from the start.
- `BridgeSession` gained one exhaustive-`when` branch that ignores benefits messages; its behavior is unchanged.

## Plan Delta

**Disposition: False assumption (blocking for T005's checker predicate; non-blocking otherwise).**

- The plan assumed one benefits page per program. Evidence: trackers sit on `/card-benefits/activity` for Platinum-type cards and in the Rewards page grid for the others, and the Rewards page shows only a subset where an activity page exists. Consequence: the read accepts two paths (ADR-0008); Phase 3 reads each card on whichever page it has.
- Amex shows 5 last digits, and Delta uses full month names ("September") as period labels. Consequence: Phase 5 parses full month names as well as "Jul - Dec".
- Scope grew by owner decision: the full benefits list with enrollment status is read and stored. Consequence: Phase 4's card page shows a benefits-list section after the tracked items.
- T005's task line ends in `(gitignored)`, which the completion checker reads as its path, so `task.T005` can never be met by a commit. Consequence: recorded as a proposed known gap for the final reconciliation; the plan stays frozen.
