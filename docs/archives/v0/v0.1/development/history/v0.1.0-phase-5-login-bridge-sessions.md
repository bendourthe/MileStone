# Session History: v0.1.0 Phase 5, Login Bridge and Session Profiles

**Date**: 2026-11-07
**Plan**: [v0.1.0-milestone-android-app.md](../../plans/v0.1.0-milestone-android-app.md)
**Branch**: `feat/v0.1.0-milestone-android-app` (worktree `MileStone-v0.1.0-milestone-android-app`)

## Outcome

A user can sign in to a sync-capable program inside MileStone, and the balance on the program's own page is read, checked, and saved. Tasks T021 to T026 are complete. The phase commit follows the Phase 2, 3, and 4 commits.

## Work Done

- Decision records: [ADR-0001](../../../../../decisions/0001-login-bridge-sessions-fixtures-logging.md) (bridge transport, per-program session profiles, fixture storage, logging rules) and [ADR-0002](../../../../../decisions/0002-open-in-app-or-browser.md) (sync stays in the embedded sign-in; each tile gains "Open in app or browser").
- `data/session/TinkSessionStore.kt`: per-program `connectedAtEpochMs` and `lastVerifiedEpochMs` in an encrypted DataStore (Tink `Aead` from an Android Keystore master key); no passwords, codes, cookies, or page HTML. `sync/webview/SessionProfiles.kt`: one WebView profile per program, and sign-out that deletes the profile (or clears the shared cookie jar and marks every connected program "Reconnect" when profiles are unsupported).
- `sync/extract/`: `BridgeProtocol` (message shapes and per-page nonce), `PageStateClassifier` (login, dashboard, or other page), `BalanceParser` (whole numbers up to 10 billion), and the document-start script `assets/extract.js`.
- `sync/webview/BridgeSession.kt` and `LoginBridge.kt`: listener and script limited to exact `https://` origins of the program's own hosts, main frame only, nonce checked; off-site links ask before opening in the browser; TLS errors cancel; a 20 s script timeout redirects once to the balance page, then fails.
- `SyncManager.applyInteractive`: the single writer; a balance of 0, or under one tenth of the stored balance, is rejected as implausible.
- `ui/auth/`: `AuthWebViewModal` (program name, current host, progress, Close), `SignInViewModel`, and the Sign in, Reconnect, and Sign out tile actions; `OpenExternally.kt` opens the program's app, or the default browser when no app handles the link.
- "Paste sign-in link" in `AuthWebViewModal`, built here for Hyatt's emailed sign-in link (planned for Phase 9): it opens a copied link only when it is https and on the program's own hosts, and never logs or stores it.
