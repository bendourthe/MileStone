## Search Benchmark on This Emulator

The local benchmark was slower than the 200 ms limit for the released code as well. Alternating runs on the same emulator, built from tag v0.5.0 and from this branch:

| Run | Code | p95 | Median |
|---|---|---|---|
| 1 | v0.5.0 | 317.8 ms | 138.4 ms |
| 2 | v0.5.1 | 535.7 ms | 181.9 ms |
| 3 | v0.5.0 | 528.1 ms | 147.3 ms |
| 4 | v0.5.1 | 309.5 ms | 129.8 ms |

Both versions fall in the same range, so the local slowness belongs to the emulator and host, not this change. Hosted CI, which measured v0.5.0 under the limit, decides this check. One real cost was found and removed on the way: card names were computed once per benefit with freshly compiled patterns, which made the benchmark's 30-second start wait time out. Names are now computed once per card from patterns compiled once.
