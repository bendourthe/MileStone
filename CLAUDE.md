# MileStone

MileStone is a new repository with a project icon and a governance baseline. Application code, a language toolchain, and a package manifest are not present.

## Version

v0.1.0, recorded as the `0.1.0` heading in `CHANGELOG.md`.

## Branch model

develop+main. `main` is the release branch. `develop` is the integration branch. Branches named `feat/`, `fix/`, `refactor/`, `ci/`, `docs/`, `chore/`, and `test/` merge through `develop`.

## Docs

Living docs stay in `docs/handbooks/`, `docs/decisions/`, `docs/README.md`, and `docs/todos.md`. Release work for v0.1 goes in `docs/releases/v0/v0.1/`.
